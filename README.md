# Proserva Conference Pages

Standalone marketing assets for Proserva's conference outreach.

| File | What it is |
|---|---|
| `proserva-masa.html` | Standalone copy of the redesigned MASA landing page (Minnesota). Opens by double-click; images are embedded, the Wistia video needs an internet connection. |
| `proserva-slate-email.html` | HTML email template for SLATE (Wisconsin), built from the Slate page content. Table-based layout with inline styles for Gmail, Outlook and Apple Mail. |

## Preview

- MASA landing page: https://htmlpreview.github.io/?https://github.com/isissi/landing-page/blob/main/proserva-masa.html
- SLATE email: https://htmlpreview.github.io/?https://github.com/isissi/landing-page/blob/main/proserva-slate-email.html

## Before sending the email

Replace these placeholders with your email platform's merge tags:

- `{{VIEW_IN_BROWSER_URL}}`
- `{{UNSUBSCRIBE_URL}}`
- `{{COMPANY_POSTAL_ADDRESS}}`
